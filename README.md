# Sağlık Tesisi Değerlendirme Standartları

Bu paket, Streamlit tabanlı uygulamayı çalıştırmak için gerekli dosyaları içerir.

## Kurulum

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Çalıştırma

```bash
streamlit run app.py
```

Varsayılan olarak `app.db` ve `logo.png` aynı klasörde aranır. Ayarlar `.env` dosyasıyla değiştirilebilir.
